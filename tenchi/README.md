# FC 天地を喰らう 解析

Capcom，1989，FC（MMC1，PRG 256K，CHR-RAM，有電池）。本宮ひろ志漫畫改編的 RPG：劉備三兄弟從楼桑村出發，一路打到曹操。中文俗稱「吞食天地」。ROM 結構與各表格式見 [docs/ROM_FORMAT.md](docs/ROM_FORMAT.md)。

不是光榮作品，不做 kaodata 匯出；頭像與漢字名以 PNG 輸出。

## 指令

```bash
# 武將、道具、商店、策略、戰鬥、遇敵、地點、出入口、寶箱、台詞、頭像、地圖 → tenchi/output/
.venv/bin/python tenchi/export.py [--rom ROM] [--out DIR] [--no-maps]

# 模擬器驗證（需 py65，約 3 分鐘；--quick 約 40 秒）：從開機玩到能走動，再用遊戲自己的程式比對
.venv/bin/python tenchi/verify.py [--quick]
```

ROM 預設直接讀 `roms/Tenchi o Kurau (Japan) (Rev A).zip`（`--rom` 也接受 .nes 或 .zip）。依賴：Pillow、openpyxl；py65（驗證用）。地圖標籤用系統的日文字型（macOS 的ヒラギノ），找不到就退回 PIL 預設字型（只有 ASCII）。

## 檔案

| 檔案 | 用途 |
|------|------|
| `rom.py` | ROM 解碼：文字與台詞控制碼、武將紀錄、頭像、漢字名字型、道具／商店、策略、兵士數表與成長、戰鬥編成、遇敵區域與名單、地點名、地圖（區塊格、2x2 chunk、metatile、地形）、出入口、傳送點、寶箱 |
| `export.py` | 匯出 CSV（UTF-8-BOM）／XLSX／PNG |
| `strips_page.py` | 兩款共用：專屬臉與橫條分組的分析、橫條總覽圖、單條 PNG、CSV 列，以及兩款合一的拼貼頁 `strips.html`（由兩款的 `export.py` 呼叫；單獨執行只重建拼貼頁） |
| `verify.py` | 模擬器驗證 |
| `tools/emu.py` | 沿用 `sangokushi/tools/nes_emu.py`（MMC1＋py65），加上按鍵腳本、fine-x 捲動、背景＋sprite 畫面、直接呼叫遊戲副程式（`call`／`call_frames`） |

## 驗證結果（`verify.py`）

從開機輸入空白名字、選會話速度、跳過開場對話，進到楼桑村的屋內後：

- **畫面**：屋內畫面的背景（關掉 sprite）與 `rom.py` 依區塊格畫出來的地圖逐 pixel 相同（61440/61440）
- **地圖格**：用遊戲自己的查表副程式 `$D83E` 查 3 種 tileset 各 1000 個隨機格子，metatile 全部與 `rom.py` 相同
- **隊伍**：劉備、関羽、張飛的ぶりょく、ちりょく、すばやさ、兵士數（314／100／100）與 WRAM 相同
- **遇敵**：用遊戲的隨機編成副程式（bank 14 `$B324`）在 1–8 區各抽 150 次，出現的武將全部在 `encounter_pools.csv` 該區名單內，雜兵只有カイゾク／サンゾク／トウゾク／へイシ；第 6 區在呂布（id 183）的旗標還在時，約一半會改成固定戰鬥 79（呂布＋へイシ 4）
- **頭像＋漢字名**：208 個有頭像的 id 逐一放進「大将」欄位、開狀態畫面，頭像 48×48 與漢字名都和畫面逐 pixel 相同（208/208）
- 拼貼頁：在瀏覽器逐一載入 207 個武將（不含 179），頁面 canvas 上的頭像與漢字名和 `rom.py` 畫的逐 pixel 相同（207/207，Playwright 比對 SHA-256；不在 `verify.py` 裡）。另確認組內選項沒有專屬臉的橫條、組內隨機 200 次都不出組
- 另手動比對：村子畫面 0 pixel 不同；大地圖畫面只有水面動畫 tile 不同

## 進度

- ✓ 文字編碼（字型 128 tile＋濁點／半濁點組字）、台詞控制碼、詞典、台詞指標表
- ✓ 武將紀錄的主要欄位、頭像（6×6 tile＋配色）、漢字名（1bpp 16×16 字型，bank 1／2）
- ✓ 兵士數表、會成長的武將的成長公式
- ✓ 道具價格、武器攻擊力、鎧／兜武裝度、商店與所在城鎮
- ✓ 策略表（習得等級、ちりょく、SP、威力、屬性、對象）
- ✓ 固定戰鬥編成、隨機遇敵的區域表與名單（含編成規則）
- ✓ 地圖：區塊格、chunk、metatile、地形、BG CHR 與調色盤；出入口、傳送點、寶箱
- 未完成：見 ROM_FORMAT.md §10（入隊事件、經驗值與戰鬥公式、道具效果、事件腳本、區塊歸屬、部分欄位意義）
