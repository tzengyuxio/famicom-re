# FC 天地を喰らうII 諸葛孔明伝 解析

Capcom，1991，FC RPG（mapper 4／MMC3，PRG 512K，CHR-RAM，有電池）。主角是劉備軍，在中國大地圖上移動，進城鎮、城、洞窟，戰鬥時以武將的兵數（へいしすう）交戰。ROM 結構與各表格式見 [docs/ROM_FORMAT.md](docs/ROM_FORMAT.md)。

這款不是光榮作品，不做 kaodata 匯出。頭像、地圖等以 PNG 輸出。

## 指令

```bash
# 武將、道具、商店、策略、經驗值、訊息、地圖連結、頭像、漢字、地圖 → tenchi2/output/
.venv/bin/python tenchi2/export.py [--rom ROM] [--out DIR]

# 模擬器驗證（需 py65，約 15 分鐘；--quick 約 5.5 分鐘，只傳送到每 10 個目標的 1 個）：從開機開新遊戲，比對 RAM 與畫面
.venv/bin/python tenchi2/verify.py [--quick]
```

ROM 預設直接讀 `roms/Tenchi o Kurau II - Shokatsu Koumei Den (Japan) (Rev A).zip`（`--rom` 也接受 .nes 或 .zip）。依賴：Pillow、openpyxl；py65（驗證用）。

## 檔案

| 檔案 | 用途 |
|------|------|
| `rom.py` | ROM 解碼：文字與訊息（含詞典字、控制碼）、武將、漢字、頭像、道具、經驗值、商店、策略、遇敵表、地圖（螢幕格、tileset、調色盤、門／傳送） |
| `export.py` | 匯出 CSV（UTF-8-BOM）／XLSX／PNG；推定各地圖在螢幕格中的範圍。頭像橫條的分析、總覽圖與拼貼頁借用 `tenchi/strips_page.py` |
| `verify.py` | 模擬器驗證 |
| `data/kanji1.txt`、`data/kanji2.txt` | 漢字字表（第 1 組 256 字、第 2 組 64 字），照 ROM 字形抄寫 |
| `tools/emu.py` | MMC3 模擬：沿用 `chuugen/tools/nes_emu.py`（py65＋暫存器層級 PPU），加上 MMC3 bank、CHR-RAM、mirroring、掃描線 IRQ |
| `tools/play.py` | 從開機的按鍵腳本：登錄紀錄、開新遊戲、跳過開場，到洛陽宮殿；打開ぶしょう清單 |

## 輸出

| 檔案 | 內容 |
|------|------|
| `generals.csv` | 256 筆武將：假名名、漢字名、ちりょく／ぶりょく／すばやさ、ぶき、ちけい、策略群、遇敵章節、未解欄位原值、頭像列位置 |
| `portraits/NNN.png`、`portraits_sheet.png` | 頭像 48×48（照ぶしょう畫面的鏡像與調色盤） |
| `portrait_strips.csv` | 頭像橫條：位置（第 1–6 條）、橫條（bank:列號）、所屬（專屬／兜／官帽）、用到的臉數與武將數、武將名單（同名合併） |
| `strips_sheet.png`、`strips/<位置>_<bank>-<列號>.png` | 橫條零件總覽：6 個位置各列出用過的橫條（2 倍、已鏡像）、幾張臉用到、哪些武將 |
| `strips_data.json` | 拼貼頁用的資料。拼貼頁本身是兩款合一的 `tenchi/output/strips.html`（見 `tenchi/README.md`），不含 231 與全空白的臉（0、109、249–255） |
| `kanji1.png`、`kanji2.png` | 漢字字形總覽 |
| `items.csv` | 道具 120 種：價格、種類（武器類別／鎧／兜／盾／其他）、攻擊力或防禦力 |
| `shops.csv` | 各城鎮（地圖編號）的武器屋、道具屋商品 |
| `tactics.csv` | 策略 54 種：類別、習得等級、可用的策略群 |
| `exp.csv` | 第 2–101 級所需經驗值 |
| `messages.csv` | 2048 段訊息。`{名字}` 是武將名，`<face:…>` 是頁首頭像，`▼` 是等按鍵 |
| `links.csv` | 門 454 筆＋傳送 149 筆：來源（推定地圖、螢幕、格）、目的地圖與位置、旗標、劇本指標 |
| `world.png` | 大地圖（格子第 68–90 列、第 2–27 欄，6656×5520；每個螢幕 16×15 格＝256×240）。只畫鏡頭看得到的螢幕，走不到、鏡頭也照不到的格子調暗到 30%。黃框是門，青框是傳送，數字是目的地圖編號 |
| `maps/map_NNN[_x].png`、`maps.csv` | 其他地圖（城鎮、城、洞窟、建築內部）。範圍是推定的，同一地圖分成幾塊時加 `_a`、`_b`…；框與數字同上 |
| `tenchi2.xlsx` | 以上各表 |

## 驗證結果（`verify.py`）

| 項目 | 方法 | 結果 |
|------|------|------|
| 能力值 | 開新遊戲後，劉備在戰鬥欄位 RAM 的ぶりょく／ちりょく／すばやさ和記錄比對 | 一致 |
| 地圖 | 洛陽宮殿（地圖 13）的畫面 BG，和 `export.py` 畫的地圖比對，起點與往下走 2 格後各一次 | 兩次都全畫面 100% 一致 |
| 傳送 | 改寫第一筆傳送記錄、在 `$F5E1` 把步伐類型 `$86` 強制成 9（傳送），從宮殿往下走一步就傳到目標。目標是大地圖鏡頭看得到的 374 個螢幕（站在中間格）＋其他地圖 234 個門／傳送的目的地；畫面 BG 與螢幕格拼出來的鏡頭範圍比對（以調色盤索引套用當下畫面的調色盤；地圖 1、3、54、81 等有水面／火光的顏色循環，`export.py` 的 PNG 是循環中的初始那一格） | 608/608 逐 pixel 一致（`--quick` 61/61） |
| 裝備 | 劉備裝備たんけん後，遊戲算出的こうげき（`$66B1 + slot`） | 10，和 ROM 的攻擊力一致 |
| 頭像與漢字 | 在ぶしょう清單把顯示的武將 id（`$6627`）依序設成 0–255，打開狀態畫面，比對 48×48 頭像與漢字名 | 256/256 逐 pixel 一致 |

另外手動看過的部分：
- 拼貼頁：在瀏覽器逐一載入 245 個武將，頁面上的頭像與 `portraits/NNN.png`、漢字名與 `rom.py` 的字形逐 pixel 相同（245/245，Playwright 比對 SHA-256）。
- 洛陽城鎮：與 `maps/map_002.png` 對得上。
- 開場訊息：解碼結果和畫面一致。
- 遇敵：在大地圖走到遇敵，畫面出現 4 個盗賊（id FD），和 §6 的流程一致。
